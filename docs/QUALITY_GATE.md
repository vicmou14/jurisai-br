# Quality gate jurídico

Antes de considerar uma resposta adequada para uso profissional, o JurisAI-BR deve:

1. recuperar fontes identificáveis para afirmações jurídicas relevantes;
2. apresentar a origem de cada resultado utilizado;
3. sinalizar quando não houver base documental suficiente;
4. separar recuperação de documentos de interpretação e conclusão;
5. registrar que o resultado é apoio à pesquisa e não substitui revisão jurídica humana;
6. preservar rastreabilidade da fonte, categoria e documento de origem.

## Critério operacional

Respostas sem fontes recuperadas devem ser tratadas como não fundamentadas. O cliente pode receber a classificação ou análise técnica do sistema, mas o módulo de pesquisa deve informar explicitamente a ausência de base documental quando a recuperação retornar vazia.
