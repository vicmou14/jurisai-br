# Templates DOCX de produção

Coloque nesta pasta exatamente dois arquivos-base:

- `template_coder.docx`
- `template_escritorio.docx`

O exportador abre o arquivo-base correspondente, preserva cabeçalho, rodapé, imagens, papel timbrado, margens e demais elementos do modelo, remove apenas o corpo textual existente e insere a nova peça.

Os arquivos devem ser os modelos originais aprovados para produção. Não substitua por arquivos de exemplo sem revisar a identidade visual.
